一间没有酒的酒吧，装着你卸下的疲惫。按心情调酒、向酒保倾诉、记录微醺日记、画自己的心情曲线。

## 🎮 功能一览

- **今日推荐**：按天轮换一杯酒，6 天一轮绝不重复
- **抽一杯**：不知道喝什么？🎲 交给命运
- **今夜特调**：按心情调酒（积分 -15），含摇酒动画
- **微醺日记**：记下今晚这一杯，心情分数 + 时间轴
- **解忧酒馆**：倾诉烦恼，酒保针对性回信（AI），可标记释怀
- **心情数据**：统计卡 + 心情趋势曲线仪表盘
- **我的**：积分任务、积分明细（流水账）、关于、使用须知
- **我的酒柜**：收藏爱喝的酒，显示点单次数
- **打卡勋章**：连续光顾 3/7/14/30 天解锁称号
- **分享海报**：酒卡一键生成暗夜琥珀风海报

## 🎫 积分系统

| 操作 | 积分 |
|---|---|
| 初始酒资 | +100 |
| 每日首次光顾 | +10 |
| 投递烦恼 | +5 |
| 写微醺日记 | +5 |
| 标记释怀 | +3 |
| 调一杯 / 抽一杯 | -15 |

## 🚀 本地运行网页版

直接双击 `ebar.html` 或用任意静态服务器：

```bash
python -m http.server 8000
```

然后打开 http://localhost:8000
