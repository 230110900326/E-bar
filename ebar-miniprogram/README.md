# 夜半微醺 · 电子酒吧小程序（部署指南）

把现有网页版改写成**原生微信小程序 + 云开发**版本：数据按用户独立存在云端，AI 酒保通过云函数调用大模型生成针对性回信（密钥只存在云端，不外泄）。

> 代码已完成并通过语法检查，本文件是「怎么把它变成别人能用的小程序」的操作手册。

## 一、上线前置（需你本人操作）

1. **注册微信小程序**：打开 https://mp.weixin.qq.com ，用微信号注册一个「小程序」账号（个人主体即可，免费）。
2. **拿到 AppID**：在「开发管理 → 开发设置」里复制 AppID（形如 `wx` 开头的字符串）。
3. **安装微信开发者工具**：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

## 二、导入项目

- 打开微信开发者工具 → 「导入项目」
- 目录选本文件夹 `ebar-miniprogram/`
- AppID 填你自己的（**别用测试号**，否则云开发受限）
- 导入后，把本项目 `project.config.json` 里的 `"appid": "touristappid"` 改成你的 AppID

## 三、开通云开发（关键）

1. 开发者工具顶部点「云开发」，开通（首次会让你新建一个环境，**免费**）
2. 记下**环境 ID**（形如 `xxx-env-abc`），打开 `app.js`，把
   `const CLOUD_ENV = "your-env-id";` 改成你的环境 ID
3. 云开发控制台 → 数据库 → 新建两个集合，权限都设为「**仅创建者可读写**」：
   - `ebar_users`（存积分 / 连续光顾天数）
   - `ebar_records`（存心事墙 / 微醺日记）

## 四、部署 AI 酒保云函数

1. 在 `cloudfunctions/aiReply` 文件夹上右键 → 「上传并部署：云端安装依赖」
2. （推荐）打开云函数 → 配置 → 环境变量，新增
   - 键：`HUNYUAN_API_KEY`
   - 值：你的腾讯混元 key（`sk-` 开头，tokenhub-intl.tencentmaas.com 的 token）
3. 不填 key 也能跑：云函数会走内置关键词兜底，只是回信没那么「针对性」；填了就变成真·AI（混元 hy3 模型）读懂你再回
4. 模型说明：酒保默认用混元 `hy3`（OpenAI 兼容格式），如换模型改 `index.js` 里的 `MODEL` 常量即可

## 五、本地预览 → 发布

1. **预览**：点「编译」，扫码即可在手机上看效果
2. **上传**：点「上传」，填版本号（如 `1.0.0`）
3. **提交审核**：登录小程序后台 → 管理 → 版本管理 → 把「体验版」提交审核
   （解忧 / 情绪记录类工具一般能过，注意文案别出现违规词）
4. **发布**：审核通过后点「发布」，别人就能在微信里搜到 / 扫码使用了

## 六、功能对照（与网页版一致）

- **今日推荐**：酒保按「距起始日的天数」轮换选一杯，6 款酒一天一杯、6 天一轮**绝不重复**；点「就喝这杯」直接调（-15 积分）
- **抽一杯**：不知道喝什么？点「🎲 抽一杯」，骰子转完随机出酒（-15 积分）
- **今夜特调**：选心情 → 摇酒动画 → 扣 15 积分出酒卡（酒名 / 基酒 / 怎么喝 / 治愈语），可「收进酒柜」「生成海报」
- **微醺日记已并入今夜特调**：特调卡片内直接「记下今晚这一杯」（心情分数 + 酒名 + 想说的话，+5 积分）
- **解忧酒馆**：写烦恼 → 消耗积分调用云函数 aiReply → 针对性回信挂心事墙 → 可标记释怀 +3 积分
- **心情数据页（pages/stats）**：独立数据仪表盘——6 张统计卡（微醺记录/平均心情/最高心情/已释怀/未释怀/连续光顾）+ 心情趋势曲线 + 微醺时间轴
- **我的页（pages/me）**：积分任务（每日+10/投递+5/日记+5/释怀+3/调酒-15/抽酒-15）、积分明细（云端 ledger 流水，每次加减分都记账）、关于、使用须知
- **我的酒柜**：独立页面（首页入口卡 → pages/shelf）收藏喜欢的特调，卡片显示「点过 X 次」（云数据库 ebar_users 的 shelf + drinkCount 字段），可移除；网页版为独立「酒柜」标签页
- **打卡勋章**：连续光顾 3 天「酒馆新客」🍺 / 7 天「常客」🥃 / 14 天「资深酒客」🪵 / 30 天「微醺诗人」🌟，置顶区显示进度
- **分享海报**：酒卡点「生成海报」→ 暗夜琥珀色海报保存到相册（需授权相册权限）
- **积分系统**：初始 100（含初始流水），每日首次光顾 +10，投递烦恼 +5，写日记 +5，释怀 +3，调酒/抽一杯 -15
- **置顶「今夜开门营业」**：连续光顾天数 + 勋章 + 积分余额 + 未释怀心事提醒

## 七、常见问题

- **云函数报错 404**：确认第三步环境 ID 已填对，且 aiReply 已「上传并部署」
- **数据不显示**：检查两个集合权限是否为「仅创建者可读写」；用体验版 / 发布版测，别用「游客模式」
- **AI 回信像套话**：去 aiReply 配置里补 `HUNYUAN_API_KEY` 环境变量，重部署一次云函数
- **海报保存失败**：在设置里允许「保存到相册」权限后重试（首次会弹权限引导）
- **趋势图空白**：需有 ≥2 条微醺日记（带心情分数）才会画曲线；数据在云端，确认已登录体验版
